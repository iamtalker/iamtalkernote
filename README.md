# iamtalkernote

![iamtalkernote 기능 한눈에 보기](docs/images/feature-overview.png)

Windows와 Android에서 함께 쓰는 로컬 마크다운 노트 앱입니다. 노트는 일반 `.md` 파일로 저장되며, 컴퓨터와 폰은 Syncthing으로 직접 동기화합니다.

> **휴대폰 공유로 바로 스크랩**  
> 웹페이지·글·사진·파일을 다른 앱에서 **공유 → iamtalkernote**로 보내면 에버노트처럼 새 노트로 저장할 수 있습니다. 저장된 스크랩은 컴퓨터와 자동 동기화되어 검색·태그·정리가 가능합니다.

## 빠른 시작

### Windows

1. [최신 릴리스](https://github.com/iamtalker/iamtalkernote/releases/latest)에서 `iamtalkernote.exe`를 받습니다.
2. 처음 실행할 때 노트 폴더를 고릅니다. 기본 폴더는 `문서\\iamtalkernote`입니다.
3. `Ctrl+N`으로 노트를 만들고 입력을 멈추면 자동 저장됩니다.

소스로 실행하려면 다음을 사용합니다.

```powershell
py -3 app/iamtalkernote.pyw
```

### Android

[Android 릴리스](https://github.com/iamtalker/iamtalkernote-android/releases/latest)에서 APK를 설치한 뒤 동기화된 노트 폴더를 한 번 고릅니다.

자세한 사용법은 [사용 설명서](docs/manual.md)를 보세요.

## 핵심 기능

- 서식 도구줄: 굵게·기울임·취소선·제목·목록·체크·인용·코드·링크·그림 단추(기호로 표시, 좁으면 줄 바꿈)
- 목록 쓰기: 목록 줄 끝에서 Enter를 치면 다음 번호·글머리·체크 표시가 이어 붙고(`1.` → `2.`), Tab·Shift+Tab으로 하위 목록을 들이고 내밉니다
- 체크박스: `- [ ] 할 일`은 렌더링 칸에서 ☐로 보이고, 누르면 ☑와 원문의 `[x]`가 함께 바뀝니다
- 그림·영상·음악 넣기(🖼 단추): 영상(mp4·webm 등)과 음악(mp3·m4a·flac 등)은 노트 안에서 재생되고, `![](x.mp4)`·`![](x.mp3)`·`<video src="…mp4">` 같은 마크다운 모양도 재생됩니다. 재생은 누르기 전에는 시작되지 않으며, 가져오기 재생 화면과 같은 화면을 씁니다
- 도움말 → **책 소개…**: 작가의 책 소개 페이지를 엽니다
- 영어 메뉴·대화창 번역: 창 오른쪽 위 언어 단추(KO / EN)로 바꿉니다
- 달력·할일·공수달력(사이드바, 옵션에서 끄기 가능), 아웃라이너 폴더, 즐겨찾기(`Ctrl+D`)
- 폴더 정보 화면: 노트북이나 가져온 폴더를 고르면 노트 칸에 폴더 이름·경로·태그 줄·메모 칸이 나옵니다(파일을 고른 것처럼). 태그는 **태그 추가** 단추를 눌러야 입력 박스가 열리고(자동완성, Enter로 쌓기, ×로 빼기, 확인을 눌러 저장), 처음부터 입력 상태로 두지 않습니다. 폴더 자체에만 붙고 안의 노트·파일에는 붙지 않으며, 색인 DB에 저장되어 원본을 건드리지 않습니다. 폴더 태그도 태그 창과 자동완성에 나옵니다. 폴더에만 붙은 태그를 누르면 그 폴더를 골라 갈 수 있고, 노트에도 붙은 태그는 누르면 노트를 거릅니다.
- 폴더 메모: 폴더 정보 화면의 메모 칸. 칸에서 나가거나 다른 폴더로 옮길 때 색인 DB에 저장됩니다.
- 폴더 정보 화면에서 노트를 열었다가 왼쪽 노트북 목록의 같은 폴더를 다시 누르면 노트가 닫히고 폴더 화면으로 돌아옵니다.
- 노트북 목록에서 폴더(노트북·저장 폴더·가져온 폴더)를 오른쪽 클릭 → **탐색기에서 폴더 열기**.
- 가져온 폴더를 고르면 노트 목록 맨 위에 그 아래의 하위 폴더가 보입니다(md 노트북과 같은 방식). 폴더 줄을 누르면 그 폴더로 갑니다.
- 상세 사용법(기능별)은 [사용 설명서](docs/manual.md)에 있습니다
- 노트북(폴더), 하위 노트북, 태그, 즐겨찾기
- Markdown 편집·렌더링, 표, 체크 목록, 코드, 수식, 각주
- `[[노트 제목]]` 링크와 `![[노트 제목]]` 포함
- 제목·본문·태그·기간 검색, 검색 저장, 정렬
- 자동 저장, 휴지통, 노트 버전, 복원 지점, 전체 변경 이력
- 중복 노트·웹 스크랩 군더더기·사용하지 않는 미디어 정리
- 본문에 글자로 박힌 그림(긴 base64 문자열)을 전체 노트에서 한 번에 리소스 파일로 분리(도구 → 본문의 글자 그림을 파일로 일괄 분리…). 제목이 붙은 그림, 링크 안의 그림 등 모든 모양을 바꿉니다. 바뀌기 전 내용은 노트 버전에 남습니다.
- 검색창 옆 **랜덤** 단추: 노트 하나를 무작위로 골라 엽니다. 목록을 모든 파일로 넓히고 그 노트를 목록에서 선택해 보여 줍니다.
- 목록 위 **← →** 단추: 뒤로·앞으로 기록(본 순서)대로 노트를 열고, 목록에서도 그 노트를 선택해 보여 줍니다. 랜덤으로 본 노트도 기록에 남습니다.
- 도구 → **중복 이미지 찾기…**: 내용이 같은 그림 파일을 묶어 보여 줍니다. 묶음을 펼치면 그 그림을 쓰는 노트가 보이고, 노트 이름을 누르면 그 노트로 갑니다. 아무 노트도 쓰지 않는 그림(휴지통 노트만 쓰던 그림 포함)은 묶음에 넣지 않습니다. 같은 창의 **그림만 있는 노트 정리…**는 글이 거의 없고 같은 그림만 가진 노트를 묶어서, 처리할 묶음을 골라 휴지통으로 보냅니다. 남기는 노트는 가장 먼저 만든 노트 1개입니다(휴지통에서 복원 가능).
- 검색 줄 아래 두 번째 줄의 **자동완성** 체크: 켜면 입력 중 제목·태그 후보가 뜨고, 후보가 목록을 밀어 내립니다(첫 결과가 가려지지 않음). 기본은 꺼짐이라 검색 결과가 바로 보입니다.
- 검색어가 제목에 있는 노트는 정렬 방식과 상관없이 위에 나옵니다. 내용에만 있는 노트는 그 아래입니다.
- **문서 내부 검색**(검색 줄 아래 두 번째 줄 체크박스): 끄면 노트와 가져온 문서 모두 **제목(태그)에서만** 찾습니다. 켜면 본문과 가져온 문서 안의 글까지 찾습니다. 가져온 폴더가 있을 때만 보입니다.
- 한글을 치는 중에도(마지막 글자가 확정되기 전에도) 검색 결과가 따라갑니다.
- 본문 검색(문서 내부 검색)은 뒤에서 찾고 끝나면 목록을 그려서, 찾는 동안 입력이 끊기지 않습니다. 검색 중에 글을 고쳐 자동 저장될 때는 색인을 다시 훑지 않고 방금 저장한 노트만 다시 맞춰 봅니다.
- 그림이 많은 글: 그림을 4장씩 동시에 화면 크기로 줄여 읽고, 한 번 읽은 그림은 기억해 두어 글을 고치거나 같은 글을 다시 열 때 또 읽지 않습니다(지금 보는 글 밖의 그림은 약 160MB까지 기억).
- 새 노트·삭제·제목 바꾸기 뒤에 목록을 다시 읽을 때 노트 폴더를 한 번만 훑습니다(노트가 많을수록 차이가 큽니다).
- 도구 → **빈 스크랩 다시 받기…**: 출처 주소는 있는데 본문이 비어 있는 옛 스크랩을 찾아 목록으로 보여 줍니다. '다음 10개 열기'로 브라우저에서 열어 조플린 클리퍼로 다시 스크랩한 뒤 '다시 채워진 빈 노트 정리…'를 누르면, 그때 노트를 다시 훑어 짝(옛 빈 노트 ← 새로 받은 노트)을 보여 주고 옛 빈 노트를 휴지통으로 보냅니다. 주소가 `http` → `https`, `www.`·`m.`, 끝의 `/`만 달라졌거나, 경로만 바뀌고 글 번호와 제목이 같은 경우도 같은 글로 봅니다. 연 줄은 [열었음], 채워진 줄은 [채워짐]으로 표시합니다.
- 메뉴줄의 **글 정리**(편집 옆): 줄 앞 공백 지우기, 줄 끝 공백 지우기, 단어 사이 빈칸 줄이기, 여러 빈 줄을 하나로, 빈 줄 전부 없애기, 같은 내용 삭제, 문단 줄 잇기, 문장마다 빈 줄 넣기, 고른 줄 합치기, 줄 가나다순 정렬(오름·내림차순), 대문자·소문자로. 메뉴 맨 아래 **설명 보기…**에서 항목마다 하는 일과 바꾸기 전·후 예시를 볼 수 있습니다. 편집 칸에서 줄을 골라 두면 그 줄들만, 고른 글이 없으면 노트 전체를 고칩니다(줄 합치기·정렬·대소문자는 고른 글이 있어야 합니다). 코드 블록(```` ``` ```` 안)은 건드리지 않고, 줄 앞 공백 지우기는 들여 쓴 하위 목록을 그대로 둡니다. 되돌리기(`Ctrl+Z`) 한 번으로 돌아옵니다.
- **찾아 바꾸기**(`Ctrl+H`, 편집 → 찾아 바꾸기): 찾기 막대 아래에 '바꿀 글' 줄이 붙습니다. **바꾸기**는 지금 가리키는 곳을 바꾸고 다음 곳으로 가고, **모두 바꾸기**는 노트 전체(편집 칸에서 여러 줄을 골라 두었으면 그 안)를 한 번에 바꿉니다. 대소문자는 구분하지 않습니다.
- 웹 클리퍼 팝업은 폴더 목록이 올 때까지 Clip 단추를 막습니다(앱을 켠 직후 눌러 저장 폴더 바로 아래로 스크랩되던 문제).
- 웹 클리퍼(로컬 서버, `127.0.0.1`). 스크랩할 때 본문 맨 위에 노트 제목과 같은 제목 줄이 있으면 빼고 저장합니다
- Android 공유 메뉴를 이용한 에버노트식 웹·파일 스크랩
- PDF·TXT·Office·오디오·동영상 외부 폴더 가져오기
- 가져온 PDF·음악·동영상을 노트 칸 안의 브라우저(WebView2)로 보기: PDF 는 쪽 넘기기·찾기가 되는 보기로, 음악·동영상은 재생 목록 화면으로 열립니다. 처음에는 연 파일의 폴더만 목록에 넣고, 화면의 폴더 고르기에서 가져온 폴더 안의 다른 폴더 하나, 또는 어느 폴더와 그 하위 폴더 전부(예: 뮤직 + 하위 폴더)로 바꿀 수 있습니다. 하위 폴더까지 고른 범위는 기억했다가 그 안의 파일을 열 때만 이어 쓰고, 범위 밖의 파일을 열면 그 파일의 폴더만 넣어 상관없는 폴더가 섞이지 않습니다. **랜덤**(겹치지 않게 한 바퀴)과 **반복**(반복 안 함 → 전체 반복 → 한 곡 반복) 단추가 있고 다음에 열 때도 그대로입니다. WebView2 런타임이 없는 PC 에서는 예전처럼 윈도 미리보기 처리기나 뽑은 글로 보입니다.
- 확장자별 연결 프로그램 지정(문서·이미지는 뷰어, MP3·MP4는 미디어 플레이어 권장)
- 노트 본문의 영상 파일(`<video src="…mp4">`, 웹 스크랩에 들어간 것): 본문 중간에 WebView2 재생 화면으로 보여 줍니다. 재생 화면을 못 쓰면 `▶ 동영상 재생` 링크로 남고, 누르면 재생 창이 열립니다.
- Android와의 Syncthing 동기화

## 노트와 파일

노트는 노트 폴더 안의 `.md` 파일입니다. 그림과 첨부는 기본적으로 `.resources`에 저장합니다.

| 폴더 | 용도 |
|---|---|
| `.resources` | 그림·첨부 |
| `.trash` | 휴지통 |
| `.history` | 변경 이력·이전 버전 |
| `.snapshots` | 복원 지점 |
| `.imported` | 가져온 파일의 폰용 요약 |
| `.sync` | 동기화 정보 |

앱을 지워도 `.md` 파일은 남습니다. 노트 폴더를 복사하면 기본 백업이 됩니다.

## 외부 폴더 가져오기

**설정 → 옵션 → 가져오기**에서 노트 폴더 밖의 폴더를 추가합니다. 원본은 수정하지 않고 읽기·색인만 합니다.

기본 확장자는 `pdf`, `txt`, `md`, `mp3`, `mp4`입니다. 다른 확장자는 옵션에서 선택하거나 직접 입력합니다. 가져온 파일의 태그와 메모는 색인에만 저장됩니다.

PDF·TXT·JPG·WEBP 같은 문서·이미지는 WaterView/NeeView 같은 뷰어를 연결하고, MP3·MP4는 Windows Media Player·VLC 같은 미디어 플레이어를 연결하는 구성이 안정적입니다. MP3·MP4를 열 때 같은 폴더의 미디어 파일을 함께 전달하므로, 여러 파일 열기나 재생목록을 지원하는 플레이어에서는 폴더 재생처럼 사용할 수 있습니다.

**설정 → 옵션 → 색인**에서 노트와 가져온 폴더의 색인 상태를 볼 수 있고, `md 노트 다시 훑기`와 `가져온 폴더 다시 읽기`로 목록을 다시 읽을 수 있습니다. 문서 안 글 색인을 켜 둔 상태에서 끝나면 "문서 내부 색인도 완료"라고 표시됩니다. 지워진 색인이 남긴 빈 공간은 자동으로 돌려주므로 색인 파일이 계속 커지지 않습니다.

## 동기화

컴퓨터와 폰은 Syncthing으로 직접 연결합니다. 노트가 서버에 업로드되는 구조가 아니며, 컴퓨터 앱은 트레이에 있어도 동기화를 계속합니다.

1. 컴퓨터 **설정 → 동기화**에서 Syncthing을 설치하고 켭니다.
2. 폰 앱의 연결 마법사에서 컴퓨터를 등록합니다.
3. 컴퓨터에서 연결 요청을 허용합니다.
4. 폰에서 받을 노트 폴더를 확인합니다.

자세한 절차는 [사용 설명서](docs/manual.md)의 동기화 장을 참고하세요.

## 알려진 한계

- Windows 전용 기능(GDI+, WebView2, Edge 재생 창, 트레이)이 있습니다.
- 스캔 PDF OCR과 오디오 음성 인식은 지원하지 않습니다.
- 가져온 원본 파일은 앱에서 편집·이동·삭제하지 않습니다.
- 유튜브는 노트 안에 직접 재생하지 않고 외부 창으로 엽니다.
- 노트 칸 안 브라우저는 PC 에 WebView2 런타임이 있어야 합니다(Windows 11 기본 포함). wma 와 Office 문서는 브라우저로 보지 않고 예전처럼 윈도 미리보기 처리기를 씁니다.

**하지 않은 개선**

- **빈 스크랩 일괄 받기**: 지금은 10개씩 브라우저 탭으로 열어 손으로 스크랩합니다. 자동으로 받으려면 클리퍼 확장(`core.js`·`background.js`)과 `clipserver.py`를 고쳐야 해서 하지 않기로 했습니다. 서비스가 끝났거나 로그인이 필요한 출처(`blog.daum.net`, `twitter.com` 등)는 다시 받아도 채워지지 않으므로, 목록에서 빼는 '포기' 표시도 없습니다.
- **설정 파일이 통째로 덮어써질 수 있는 경로**: `store.read_config()`는 8번 읽기에 실패하면 빈 설정을 돌려주고, `write_config()`는 그 위에 고친 값만 넣어 저장합니다. 설정 파일이 깨진 채 남으면 다음 저장 때 노트 폴더 위치·가져온 폴더·저장된 검색이 사라질 수 있습니다(코드로만 확인, 재현하지 않음).
- **시험을 한 번에 돌리는 실행기와 자동 검사(CI)가 없습니다.** `tools/test_*.py`를 하나씩 돌려야 합니다.
- **낡은 시험 3개**: `test_search_history.py`(가짜 객체에 `ac_gap` 없음), `test_tag_scope.py`(가짜 객체에 `content_search` 없음), `test_sync_engine.py`(syncthing.exe 경로 인자가 있어야 돎). `test_refresh_all.py`는 다른 창과 함께 돌리면 포커스 때문에 가끔 실패합니다.
- **본문 검색 자체의 시간**은 그대로입니다(색인의 본문 사본 전체를 훑음, 실제 색인 116MB 에서 0.2~0.3초). 뒤에서 돌려 입력만 안 끊기게 했습니다.
- **폰과 PC 의 본문 검색 결과가 다를 수 있습니다**: 폰은 본문 사본을 30만 자에서 자르고 2MB 넘는 노트는 본문을 색인하지 않습니다. PC 는 제한이 없습니다.
