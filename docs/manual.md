## 1. 설치

### Windows

1. [최신 릴리스](https://github.com/iamtalker/iamtalkernote/releases/latest)에서 `iamtalkernote.exe`를 받습니다.
2. SmartScreen이 표시되면 **추가 정보 → 실행**을 선택합니다.
3. 첫 실행에서 노트 폴더를 선택합니다. 기본값은 `문서\iamtalkernote`입니다.

소스로 실행하려면 `py -3 app/iamtalkernote.pyw`를 씁니다.

### Android

1. [Android 릴리스](https://github.com/iamtalker/iamtalkernote-android/releases/latest)에서 APK를 설치합니다.
2. 컴퓨터와 동기화된 노트 폴더를 선택합니다.

## 2. Windows 앱: 화면과 기본 조작

### 화면 구성

왼쪽부터 노트북·태그 목록, 노트 목록, 편집 칸, 렌더링 칸입니다. **보기** 메뉴에서 노트북 보기, 태그 보기, 노트 목록 보기, 문법 해설 보기를 켜고 끌 수 있습니다.

### 보기 방식 세 가지

**보기 → 마크다운만 / 마크다운 + 렌더링 / 렌더링만**으로 바꿉니다.

- **마크다운만**: 원문만 씁니다.
- **마크다운 + 렌더링**: 원문과 완성된 모습을 나란히 봅니다. 한쪽을 옮기면 다른 쪽도 같은 자리로 따라갑니다.
- **렌더링만**: 완성된 모습만 봅니다. 여기서 체크박스를 누르거나 글을 우클릭해 고칠 수 있습니다.

`Ctrl+L`(편집기 레이아웃 전환)이나 `Ctrl+E`로 순서대로 바꿉니다. `Ctrl+/`는 문법 해설 칸을 켜고 끕니다.

### 노트 만들기와 저장

- `Ctrl+N`: 새 노트, `Ctrl+Shift+N`: 새 노트북, **파일 → 새 하위 노트북**: 노트북 안의 노트북
- 입력을 멈추면 자동 저장됩니다. 저장 중에는 따로 누를 필요가 없습니다.
- 그림은 노트 폴더의 `.resources`에 저장됩니다.
- `Ctrl+Shift+T` 또는 **편집 → 날짜 및 시간 삽입**으로 현재 날짜·시각을 넣습니다.

### 노트 속성과 버전

- **편집 → 노트 속성…**: 노트의 만든 날, 고친 날, 태그, 출처 주소 등을 봅니다.
- **편집 → 노트 버전…**: 저장 전에 남은 이전 내용으로 돌아갈 수 있습니다.
- **편집 → 비슷한 노트 찾기…**: 지금 노트와 내용이 닮은 노트를 찾습니다.

## 3. 글쓰기: 서식·목록·체크박스

### 서식 도구줄

편집 칸 위의 도구줄에 자주 쓰는 서식이 기호 단추로 있습니다. 단추에 마우스를 올리면 이름과 단축키가 보입니다. 칸이 좁으면 단추가 줄을 바꿔 한 줄에 다 보이게 배치됩니다.

| 단추 | 하는 일 | 단축키 |
|---|---|---|
| ↶ / ↷ | 실행 취소 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` |
| **B** | 굵게 | `Ctrl+B` |
| *I* | 기울임꼴 | `Ctrl+I` |
| ~~S~~ | 취소선 | |
| H | 제목 | |
| • | 글머리 목록 | |
| 1. | 번호 목록 | |
| ☑ | 체크 목록(할 일) | |
| ❝ | 인용 | |
| `</>` | 코드 | |
| 🔗 | 링크 만들기 | `Ctrl+K` |
| 🖼 | 그림·영상·파일 넣기 | |

글을 골라 두고 단추를 누르면 그 글을 감쌉니다. 줄 단위 서식(목록·인용·체크)은 고른 줄마다 적용됩니다.

같은 기능이 **편집** 메뉴에도 있습니다. 제목은 **편집 → 제목**에서 1~4 단계와 본문을 고르고, 가로줄·표·코드 블록은 **편집** 메뉴에서 넣습니다.

### 목록: Enter로 이어 쓰기

목록 줄의 끝에서 `Enter`를 누르면 다음 줄에 같은 표시가 붙습니다.

- `1. 예시` → `2. ` (9 다음은 10)
- `- 가` → `- `
- `- [ ] 할 일` → `- [ ] ` (체크 목록은 빈 칸으로 이어짐)
- 내용 없이 표시만 있는 줄(`2. `)에서 `Enter`를 누르면 표시를 지우고 목록을 끝냅니다.

`[[` 제목 후보 목록이 떠 있을 때는 이 기능이 쉬고, 평소 줄 바꿈으로 돌아갑니다.

### 목록: Tab으로 들여쓰기

목록 줄에서 **Tab**을 누르면 그 줄이 두 칸 들여쓰기 되어 하위 목록이 됩니다. **Shift+Tab**은 한 단계 내어씁니다. 여러 줄을 골라 두고 누르면 고른 줄이 모두 옮겨집니다. 목록이 아닌 줄의 Tab은 평소처럼 탭 글자를 넣습니다.

```markdown
1. 준비
  1. 재료 사기
  2. 도구 챙기기
2. 실행
```

### 체크박스

`- [ ] 할 일`은 렌더링 칸에서 ☐로 보입니다. ☐를 누르면 ☑로 바뀌고, 원문에서도 `[ ]`가 `[x]`로 바뀝니다. 다시 누르면 되돌아갑니다. 같은 노트에 체크 항목이 여러 개 있어도 누른 항목만 바뀝니다.

체크 목록을 만들려면 도구줄의 ☑ 단추를 누르거나 `- [ ] 할 일`처럼 직접 씁니다.

### 표·코드·수식·각주

표, 코드 블록(```` ``` ````), 인용, 수식, 각주를 마크다운 문법 그대로 쓸 수 있습니다. 렌더링 칸에서 완성된 모습으로 봅니다.

## 4. 그림·영상·파일 넣기

도구줄의 🖼 단추(또는 편집 메뉴의 해당 항목)를 누르면 파일 고르기 창이 열립니다.

- 파일 종류 필터: **그림·영상**, 그림, 영상, 모든 파일
- 고른 파일은 노트 폴더의 `.resources`로 복사되고, 노트에는 `![이름](.resources/...)` 같은 링크가 들어갑니다.
- 그림은 노트에 바로 보입니다.
- 영상(`.mp4`, `.webm`, `.m4v`, `.ogv`)은 **노트 안에서 재생**됩니다.

영상은 다음 모양으로 써도 노트 안에서 재생됩니다. 이 모양은 웹 클리퍼로 가져온 노트에서도 같습니다.

```markdown
![클립](clip.mp4)
<video controls src="https://example.com/clip.mp4"></video>
[영상](clip.mp4)
```

재생 화면은 본문 칸 너비에 맞춘 16:9 화면입니다. 재생 화면을 쓸 수 없는 PC에서는 `▶ 동영상 재생` 링크로 보이고, 누르면 재생 창이 열립니다. 편집 칸에서는 글자(링크)로 보입니다.

## 5. 글 정리와 찾아 바꾸기

### 글 정리 (메뉴줄 **글 정리**)

편집 칸의 글을 한 번에 다듬습니다. 줄을 골라 두면 그 줄들만, 고른 글이 없으면 노트 전체를 고칩니다. 코드 블록 안은 건드리지 않고, `Ctrl+Z` 한 번으로 돌아옵니다.

| 항목 | 하는 일 |
|---|---|
| 줄 앞 공백 지우기 | 줄 맨 앞의 공백·탭·전각 공백을 지웁니다. 들여 쓴 하위 목록은 그대로 둡니다. |
| 줄 끝 공백 지우기 | 줄 맨 끝의 공백을 지웁니다(공백 두 칸으로 만든 줄 바꿈도 사라집니다). |
| 단어 사이 빈칸 줄이기 | 글자 사이에 두 칸 넘게 띈 곳을 한 칸으로 줄입니다. 인라인 코드 안은 건드리지 않습니다. |
| 여러 빈 줄을 하나로 | 빈 줄이 2줄 이상 이어진 곳을 1줄로 줄입니다. |
| 빈 줄 전부 없애기 | 빈 줄을 모두 없앱니다. |
| 같은 내용 삭제 | 같은 줄이 또 나오면 뒤의 것을 지웁니다. |
| 문단 줄 잇기 | 빈 줄로 나뉜 문단마다 한 줄로 잇습니다(PDF에서 복사해 줄이 끊긴 글). 제목·표·목록은 그대로 둡니다. |
| 문장마다 빈 줄 넣기 | 줄 하나에 붙어 있는 문장 사이에 빈 줄을 넣어, 문장마다 줄을 나눕니다. |
| 고른 줄 합치기 | 고른 줄들을 한 줄로 합칩니다. |
| 줄 가나다순 정렬 | 고른 줄들을 오름·내림차순으로 정렬합니다. |
| 대문자로 · 소문자로 | 고른 글자의 영문 대소문자를 바꿉니다. |

**문장마다 빈 줄 넣기** 예:

```text
오늘은 날씨가 좋다. 공원에 갔다. 돌아오는 길에 빵을 샀다.
```

이 글을 고르고 **문장마다 빈 줄 넣기**를 실행하면 다음처럼 바뀝니다.

```text
오늘은 날씨가 좋다.

공원에 갔다.

돌아오는 길에 빵을 샀다.
```

항목마다 하는 일과 바꾸기 전·후 예시는 **글 정리 → 설명 보기…**에서 볼 수 있습니다.

줄 합치기, 정렬, 대문자·소문자는 먼저 글을 골라야 합니다.

### 찾아 바꾸기 (`Ctrl+H`, **편집 → 찾아 바꾸기**)

찾기 막대 아래에 **바꿀 글** 줄이 붙습니다.

- **바꾸기**(또는 바꿀 글 칸에서 `Enter`): 주황색으로 가리킨 곳을 바꾸고 다음 곳으로 갑니다.
- **모두 바꾸기**: 노트 전체를 바꿉니다. 편집 칸에서 여러 줄을 골라 두었으면 그 안에서만 바꿉니다.

대소문자는 구분하지 않습니다. 정규식은 쓸 수 없습니다.

## 6. 노트 링크와 검색

### 노트끼리 잇기

- `[[노트 제목]]`: 다른 노트로 가는 링크입니다. 입력 중에 제목 후보가 뜹니다.
- `![[노트 제목#특정 절]]`: 다른 노트의 내용을 본문에 포함합니다.
- **보기 → 문법 해설 보기**(`Ctrl+/`)에서 문법을 바로 확인할 수 있습니다.

### 검색

| 방법 | 하는 일 |
|---|---|
| `Ctrl+F` (**편집 → 문서에서 찾기**) | 지금 노트 안에서 찾습니다. |
| `Ctrl+Shift+F` (**편집 → 모든 파일에서 검색**) | 노트 전체와 가져온 파일에서 찾습니다. |

검색 문법(**도움말 → 검색 문법**):

- 공백 = AND: `회의록 예산`
- `OR`, `NOT`: `회의록 AND (예산 OR 일정) NOT 취소` (대문자만 연산자로 인식합니다)
- 기호도 가능: `&`, `|`, `!`
- `"정확한 구절"`
- 태그: 본문의 `#프로젝트`, 또는 `태그: a, b` 줄
- 기간: `date:20240101`(그 날), `date:202401`(그 달), `date:2024`(그 해), `date:20101011-20240104`(그 사이), `date:20240101-`(그날부터), `date:-20240104`(그날까지). `날짜:`·`기간:`으로 써도 됩니다.

검색 조건은 저장해 두고 다시 쓸 수 있습니다. 검색어가 제목에 있는 노트는 정렬과 관계없이 위에 나오고, 내용에만 있는 노트는 그 아래에 나옵니다.

- **자동완성** 체크를 켜면 입력 중에 제목·태그 후보가 뜨고, 후보가 목록을 밀어 내립니다. 기본은 꺼져 있습니다.
- **문서 내부 검색**을 끄면 제목과 태그에서만 찾고, 켜면 본문과 가져온 문서의 글까지 찾습니다. 가져온 폴더가 있을 때만 보입니다.
- 한글을 치는 중에도 결과가 따라갑니다.

## 7. 노트북·태그·즐겨찾기

### 노트북

- **파일 → 새 노트북**(`Ctrl+Shift+N`) / **새 하위 노트북**: 폴더처럼 노트를 묶습니다.

### 태그

- 본문의 `#태그`, 머리말의 `tags:`, 문서 아래의 `태그: a, b` 줄을 태그로 읽습니다.
- 태그 목록에서 이름 바꾸기, 삭제, 합치기를 할 수 있습니다.
- **도구 → 자동 태그 추가…**: 노트 내용을 분석해 태그를 추천하고, 고른 것만 노트에 넣습니다.

### 즐겨찾기

- 노트를 고른 상태에서 `Ctrl+D`(또는 우클릭 → 즐겨찾기 추가)로 즐겨찾기에 넣거나 뺍니다. 편집 칸 위의 별 표시로도 같습니다.
- 사이드바의 **즐겨찾기**에서 모아 봅니다. 즐겨찾기 기능은 **옵션**에서 끌 수 있습니다.

## 8. 달력·할일·공수

사이드바의 **달력·할일**을 고르면 노트 자리에 달력과 할일 화면이 열립니다. 이 기능도 **옵션**의 기능 항목에서 끌 수 있습니다.

- **달력**: 날짜를 누르면 그 날의 할일이 아래에 나옵니다. 공휴일은 표시되고, 옵션의 **구글 달력에서 대한민국 공휴일 가져오기**를 켜면 로그인 없이 공개 달력에서 한 달에 한 번 받아 씁니다. 받지 못하면 내장 표(2024~2030년)를 씁니다. 오늘은 **오늘** 단추로 갑니다.
- **할일 추가**: 날짜를 고른 뒤 할일을 적습니다. 할일 앞의 ☐를 누르면 오늘 날짜로 완료됩니다.
- 할일을 우클릭하면 **변경**과 **삭제**를 합니다. **오늘 완료된 항목 숨기기**로 정리할 수 있습니다.
- **공수달력**(옵션에서 켜기): 건설·일용직 계산용입니다. 날짜마다 공수를 적으면, 화면 아래에 이 달의 공수 합계, 일당(합계 × 단가), 일비(출근한 날 수 × 일비)를 보여 줍니다. 공수는 **공수 직접 입력…**으로 소수 값도 넣을 수 있고, **공수 지우기**로 없앱니다.

## 9. 아웃라이너 폴더

노트 폴더 가운데 **아웃라이너**로 만든 폴더에서는 글을 WorkFlowy처럼 점(●) 계층으로 씁니다. 항목마다 한 줄씩 쓰고, 항목을 들여쓰면 하위 항목이 됩니다.

- `Enter`: 새 항목
- `Tab` / `Shift+Tab`: 들여쓰기 / 내어쓰기
- 줄 맨 앞에서 `Backspace`: 앞 항목에 붙이기(빈 항목이면 지우기)
- 항목을 접고 펼쳐 긴 목록을 정리할 수 있습니다.

저장되는 파일은 일반 마크다운 목록(`.md`)이라 다른 편집기나 폰에서도 그대로 열립니다. 아웃라이너 기능도 **옵션**에서 끌 수 있습니다.

## 10. 목록 도구: 랜덤·이동·새로 고침

- **랜덤**: 검색 줄 옆 단추로 노트 하나를 무작위로 고릅니다. 목록을 모든 파일로 넓혀 그 노트를 선택해 보여 줍니다. **도구·편집 메뉴의 랜덤 노트 열기**도 같습니다.
- **← →** 단추(또는 **이동 → 뒤로** `Ctrl+-` / **앞으로** `Ctrl++`): 본 순서대로 노트를 오갑니다. 랜덤으로 본 노트도 기록에 남습니다.
- **보기 → 노트 목록 보기**(`Ctrl+Shift+L`): 노트 목록을 켜고 끕니다.
- **보기 → 새로 고침**(`F5`, 또는 목록 위 ⟳): 앱 밖(탐색기 등)에서 노트북·노트를 지우거나 옮겼을 때 다시 읽습니다.

## 11. 도구 메뉴: 정리와 점검

| 항목 | 하는 일 |
|---|---|
| 복원 지점… | 여러 노트를 한 시점으로 되돌립니다. 필요할 때 직접 만들어 둘 수 있습니다. |
| 전체 변경 이력… | 수정·이동·삭제 기록을 시간순으로 봅니다. |
| 자동 태그 추가… | 노트 내용을 분석해 태그를 추천합니다. 고른 것만 넣습니다. |
| 중복 노트 찾기… | 내용이 같거나 거의 같은 노트를 묶어 보여 줍니다. |
| 스크랩 군더더기 정리… | 웹 스크랩에 붙은 광고·메뉴 같은 불필요한 글을 찾아 지웁니다. |
| 안 쓰는 미디어 파일 정리… | 어느 노트도 쓰지 않는 그림·첨부를 찾아 휴지통으로 보냅니다. |
| 본문의 글자 그림을 파일로 일괄 분리… | 본문에 글자로 박힌 긴 그림(base64)을 파일로 옮기고 노트를 고칩니다. 바뀌기 전 내용은 노트 버전에 남습니다. |
| 중복 이미지 찾기… | 내용이 같은 그림 파일을 묶습니다. 묶음을 펼치면 그 그림을 쓰는 노트가 보이고, 노트 이름을 누르면 그 노트로 갑니다. **그림만 있는 노트 정리…**는 글이 거의 없고 같은 그림만 가진 노트를 묶어, 처리할 묶음을 골라 휴지통으로 보냅니다. 남기는 노트는 가장 먼저 만든 1개입니다. |
| 빈 스크랩 다시 받기… | 출처 주소는 있는데 본문이 빈 옛 스크랩을 찾습니다. **다음 10개 열기**로 브라우저에서 열어 조플린 클리퍼로 다시 스크랩한 뒤, **다시 채워진 빈 노트 정리…**를 누르면 짝을 찾아 옛 빈 노트를 휴지통으로 보냅니다. 연 줄은 `[열었음]`, 채워진 줄은 `[채워짐]`으로 표시합니다. |

## 12. 안전망: 휴지통·노트 버전·복원 지점·변경 이력

- **휴지통**(**파일 → 휴지통**): 삭제한 노트는 바로 사라지지 않고 `.trash`에 보관됩니다. 여기서 복원하거나 비울 수 있습니다.
- **노트 버전**(**편집 → 노트 버전…**): 저장 전 내용을 보관하므로 이전 글로 돌아갈 수 있습니다.
- **복원 지점**(**도구 → 복원 지점…**): 여러 노트를 한 시점으로 되돌립니다.
- **전체 변경 이력**(**도구 → 전체 변경 이력…**): 어떤 노트를 언제 고치거나 옮기거나 지웠는지 기록합니다.
- **설정 → 노트 버전 설정**에서 노트 버전을 얼마나 보관할지 정합니다.

## 13. 웹 클리퍼

조플린 클리퍼 확장을 설치한 뒤, **설정 → 웹 클리퍼 설정**에서 토큰을 확인해 클리퍼에 입력합니다. 클리퍼 서버는 이 컴퓨터의 `127.0.0.1`에서만 열립니다.

스크랩하면 본문 맨 위에 `원본: 주소` 줄이 붙습니다. 이 줄은 렌더링 칸에서는 숨기고, 문서 정보의 주소로 보여 줍니다. 본문 첫 줄이 노트 제목과 같으면 중복을 피하려고 뺍니다.

## 14. 외부 폴더 가져오기와 노트 칸 안의 보기

### 가져오기 설정

1. **파일 → 폴더 가져오기…**(또는 **설정 → 옵션 → 가져오기**)를 엽니다.
2. 노트 폴더 밖의 폴더를 추가합니다.
3. 읽을 확장자를 고릅니다. 기본은 `pdf`, `txt`, `md`, `mp3`, `mp4`입니다. 직접 입력할 수도 있습니다.
4. **지금 다시 읽기**를 누릅니다.

원본 파일은 수정하지 않습니다. 가져온 파일의 태그와 메모는 색인에만 저장됩니다. **설정 → 색인**에서 읽기 상태를 보고, `md 노트 다시 훑기`와 `가져온 폴더 다시 읽기`로 목록을 다시 읽을 수 있습니다.

### 노트 칸 안에서 보기

가져온 **PDF, 음악**(mp3, flac, m4a, ogg, wav, opus), **동영상**(mp4, webm)은 목록에서 누르면 노트 칸 안의 브라우저로 바로 보입니다.

- PDF는 쪽 넘기기와 찾기가 되는 보기로 열립니다.
- 음악·동영상은 재생 목록 화면으로 열리고, 곡이 끝나면 다음 곡으로 넘어갑니다.
- 처음에는 연 파일이 든 폴더의 곡만 목록에 들어갑니다. 재생 막대 아래의 폴더 고르기에서 다른 폴더 하나를 고르거나, **○○ + 하위 폴더**를 골라 그 아래의 곡을 모두 넣을 수 있습니다(예: 뮤직 + 하위 폴더 → 장르별 폴더 전부).
- **랜덤**을 켜면 목록을 섞어 겹치지 않게 한 바퀴 돌고, **반복** 단추는 누를 때마다 반복 안 함 → 전체 반복 → 한 곡 반복으로 바뀝니다. 다음에 열 때도 그대로입니다.
- 열기만 해서는 재생하지 않습니다. 다른 노트로 가거나 창을 트레이로 보내면 재생이 멈춥니다.
- 머리줄의 **뽑은 글로 보기**를 누르면 색인해 둔 글로 바뀝니다.

이 기능은 PC에 WebView2 런타임이 있어야 합니다(Windows 11에는 기본으로 있습니다). 없으면 윈도 미리보기 처리기나 뽑은 글로 보입니다.

### 확장자별 연결 프로그램

가져온 파일을 우클릭해 확장자마다 연결 프로그램을 지정할 수 있습니다.

- PDF·TXT·JPG·WEBP: WaterView, NeeView 같은 문서·이미지 뷰어
- MP3·MP4: Windows Media Player, VLC 같은 미디어 플레이어

MP3·MP4를 열 때는 같은 폴더의 미디어 파일도 함께 넘깁니다. 재생목록을 지원하는 플레이어라면 폴더 안의 곡을 이어서 재생할 수 있습니다. 반복·셔플은 플레이어 설정을 따릅니다.

## 18. Android 앱

서랍에는 모든 노트, 노트북, 태그, 가져온 파일, 휴지통, 설정이 있습니다. 노트를 길게 누르면 여러 노트를 고를 수 있습니다.

노트를 열고 **편집**을 누르면 자동 저장됩니다. 검색, 태그, 노트 버전, 공유, 이름 바꾸기, 옮기기, 휴지통 기능을 쓸 수 있습니다.

### 공유로 스크랩하기

에버노트처럼 휴대폰의 공유 메뉴에서 바로 스크랩할 수 있습니다.

1. 브라우저나 다른 앱에서 저장할 웹페이지·글·사진·파일을 엽니다.
2. **공유**를 누르고 공유 대상에서 **iamtalkernote**를 고릅니다.
3. 제목과 저장할 노트북을 확인한 뒤 저장합니다.

스크랩은 일반 노트로 저장되므로 태그·검색·즐겨찾기·휴지통을 그대로 씁니다. Syncthing이 연결되어 있으면 컴퓨터에서도 곧바로 보입니다.

컴퓨터가 가져온 파일의 요약은 `.imported`를 통해 목록과 검색에 나옵니다. 요약은 읽기 전용입니다.

## 19. 컴퓨터와 폰 동기화

1. 컴퓨터 **설정 → 동기화 설정**에서 Syncthing을 설치하고 켭니다.
2. 폰 앱의 **설정 → 동기화 → 연결 마법사**를 엽니다.
3. 폰에서 컴퓨터를 등록합니다.
4. 컴퓨터에 뜨는 연결 요청을 허용합니다.
5. 폰에서 받을 노트 폴더를 확인합니다.

컴퓨터 앱은 트레이에 있어도 동기화를 계속합니다. 처음 연결하기 전에 양쪽 노트 폴더를 백업해 두세요.

동기화가 보이지 않으면 두 기기가 같은 네트워크인지, 컴퓨터 앱이 실행 중인지 확인합니다. 충돌 파일은 자동으로 덮어쓰지 말고 두 파일을 비교하세요.

## 20. 파일 구조와 백업

```text
노트 폴더/
├─ *.md
├─ .resources/  그림·영상·첨부
├─ .trash/      휴지통
├─ .history/    변경 이력·노트 버전
├─ .snapshots/  복원 지점
├─ .imported/   가져온 파일 요약
└─ .sync/       동기화 정보
```

노트 폴더 전체를 복사하면 가장 간단한 백업입니다. 앱 밖에서 `.md`를 고치면 다음 실행 때 외부 수정으로 기록될 수 있습니다.

## 21. 한계

- 일부 기능(노트 칸 안의 브라우저, 재생 화면, 윈도 미리보기)은 Windows 전용이며 WebView2가 필요합니다.
- 스캔 PDF의 글자 인식(OCR)과 음성 인식은 지원하지 않습니다.
- 가져온 원본 파일은 앱에서 고치거나 옮기거나 지우지 않습니다.
- 유튜브는 노트 안에서 재생하지 않고 외부 창으로 엽니다.
- 편집 칸에서는 영상이 글자(링크)로 보입니다. 재생 화면은 렌더링 칸에서 봅니다.
- Android에서 가져온 파일의 원본을 열려면 그 파일도 동기화되어 있어야 합니다.

## 22. 도움말과 업데이트

- **도움말 → 사용 설명서 (GitHub)…**(`F1`): 이 문서를 엽니다.
- **도움말 → 검색 문법**: 검색 문법을 짧게 보여 줍니다.
- **도움말 → 안드로이드 앱 내려받기 (APK)…**: 폰 앱의 최신 릴리스를 엽니다.
- **도움말 → 책 소개…**: 작가의 책 소개 페이지를 엽니다.
- **도움말 → 오픈소스 라이선스…**: 포함된 제3자 소프트웨어의 라이선스 전문을 봅니다.
- **도움말 → 업데이트 확인…**: 새 버전이 있으면 알려 주고 내려받아 설치합니다.
- **도움말 → iamtalkernote 정보**: 버전과 노트 폴더 위치를 보여 줍니다.
