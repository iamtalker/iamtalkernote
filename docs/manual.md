## 1. 설치와 첫 실행

### Windows

1. [최신 릴리스](https://github.com/iamtalker/iamtalkernote/releases/latest)에서 `iamtalkernote.exe`를 받습니다.
2. SmartScreen이 뜨면 **추가 정보 → 실행**을 누릅니다.
3. 처음 실행하면 노트 폴더를 고릅니다. 기본값은 `문서\iamtalkernote`입니다.

소스로 실행하려면 `py -3 app/iamtalkernote.pyw`를 씁니다.

앱은 한 번에 하나만 켜집니다. 이미 실행 중일 때 다시 실행하면 새 창을 띄우지 않고 기존 창을 보여 줍니다.

앱 설정은 `%APPDATA%\iamtalkernote\config.json`에 저장됩니다. 노트 자체는 노트 폴더의 `.md` 파일입니다.

### Android

1. [Android 릴리스](https://github.com/iamtalker/iamtalkernote-android/releases/latest)에서 APK를 설치합니다.
2. 컴퓨터와 동기화된 노트 폴더를 고릅니다.

## 2. 화면 구성

왼쪽부터 **노트북·태그**, **노트 목록**, **편집 칸**, **렌더링 칸**입니다. 사이드바 맨 위에는 **즐겨찾기**, **저장된 검색**, **달력·할일**, **아웃라이너 폴더**가 바로가기로 있습니다(옵션에서 끌 수 있습니다).

- **보기 → 노트북 보기 / 태그 보기 / 노트 목록 보기 / 문법 해설 보기**로 영역을 숨기거나 켭니다.
- **문법 해설 보기**(`Ctrl+/`)를 켜면 마크다운 문법 목록이 나오고, 항목을 누르면 그 문법이 편집 칸에 들어갑니다.
- 창 오른쪽 위의 **언어 단추**로 한국어와 영어를 바꿉니다(27장).

### 보기 방식 세 가지

**보기 → 마크다운만 / 마크다운 + 렌더링 / 렌더링만**(또는 옵션 → 일반의 편집기 보기)으로 바꿉니다.

- **마크다운만**: 원문만 씁니다.
- **마크다운 + 렌더링**: 원문과 완성된 모습을 나란히 봅니다. 한쪽을 옮기면 다른 쪽도 같은 자리로 따라옵니다.
- **렌더링만**: 완성된 모습만 봅니다. 체크박스를 누르거나 글을 우클릭해 고칠 수 있습니다.

`Ctrl+L` 또는 `Ctrl+E`로 세 방식을 차례로 바꿉니다.

## 3. 노트 만들기와 저장

### 만들기

- `Ctrl+N`: 새 노트. **파일 → 새 노트**도 같습니다.
- `Ctrl+Shift+N`: 새 노트북. **파일 → 새 하위 노트북**은 노트북 안에 노트북을 만듭니다.
- 제목을 쓰지 않은 새 노트는 본문 첫 줄(머리말·빈 줄·마크다운 기호를 뺀 첫 글)이 제목이 됩니다.

### 제목

노트의 제목은 파일 이름입니다. 제목을 바꾸면 파일 이름도 바뀝니다. 같은 폴더 안에서는 파일 이름이 같으므로 같은 제목을 둘 수 없습니다. 위키 링크를 켜 두면 같은 제목 막기가 더 엄격하게 적용됩니다(10장).

### 저장

- 입력을 멈추면 자동 저장됩니다. 따로 저장 버튼은 없습니다.
- 저장하기 전 내용은 노트 버전에 남습니다(19장).
- **편집 → 날짜 및 시간 삽입**(`Ctrl+Shift+T`)으로 지금 날짜와 시각을 넣습니다.

### 노트 속성

**편집 → 노트 속성…**은 노트의 정보 창입니다(조플린의 ⓘ 창과 같은 역할). 노트에 대한 정보를 한 곳에서 봅니다.

## 4. 서식과 마크다운 문법

### 서식 도구줄

편집 칸 위에 자주 쓰는 서식이 기호 단추로 있습니다. 단추 위에 마우스를 올리면 이름과 단축키가 나옵니다. 칸이 좁으면 단추가 줄을 바꿔 한 줄에 다 보이게 배치됩니다.

| 단추 | 하는 일 | 단축키 |
|---|---|---|
| ↶ / ↷ | 실행 취소 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` |
| **B** | 굵게 | `Ctrl+B` |
| *I* | 기울임꼴 | `Ctrl+I` |
| ~~S~~ | 취소선 | |
| H | 제목 | |
| • | 글머리 목록 | |
| 1. | 번호 목록 | |
| ☑ | 체크 목록(할 일) | |
| ❝ | 인용 | |
| `</>` | 코드 | |
| 🔗 | 링크 만들기 | `Ctrl+K` |
| 🖼 | 그림·영상·파일 넣기 | |

글을 고른 뒤 단추를 누르면 그 글을 감쌉니다. 줄 단위 서식(목록·인용·체크)은 고른 줄마다 붙습니다.

### 편집 메뉴의 서식

**편집** 메뉴에는 같은 서식에 더해 다음이 있습니다.

- **제목 → 제목 1~4 / 본문**: 제목 단계를 정합니다.
- **가로줄**, **표**, **코드 블록**: 블록을 넣습니다.
- **번호 매기기 목록**, **글머리 기호 목록**, **인용**: 줄 서식입니다.
- **취소선**, **코드**: 글자 서식입니다.

### 문법 해설 목록

문법 해설 칸(`Ctrl+/`)에는 다음 문법이 모여 있습니다. 항목을 누르면 편집 칸에 들어갑니다.

- **글자**: 굵게 `**글**`, 기울임 `*글*`, 취소선 `~~글~~`, 코드 `` `글` ``, 위 첨자 `<sup>`, 아래 첨자 `<sub>`
- **목록·인용**: 글머리 `- 항목`, 번호 `1. 항목`, 체크 `- [ ] 할 일`, 인용 `> 글`, 들여쓰기, 내어쓰기
- **넣기**: 링크 `[글](주소)`, 노트 링크 `[[노트 제목]]`, 자동 링크 `<https://…>`, 그림 `![글](그림.png)`, 유튜브 영상, 표, 가로줄, 코드 블록, 언어 지정 코드(```` ```python ````)
- **확장**: 수식 `$a^2$`와 블록 `$$ … $$`, 접기 `<details>`, 목차, 각주, 날짜·시간, 태그 `#태그`

### 노트 본문 확장

- **수식**: `$…$`(줄 안)와 `$$…$$`(블록)을 렌더링 칸에서 식으로 보입니다.
- **각주**: 본문의 각주 표시를 아래 목록으로 모아 보입니다.
- **접기**: `<details>`로 감싸면 접을 수 있습니다.
- **목차**: 목차 블록을 넣으면 제목 목록이 나옵니다.

## 5. 목록·체크박스·표·인용

### Enter로 이어 쓰기

목록 줄 끝에서 `Enter`를 누르면 다음 줄에 같은 표시가 붙습니다.

- `1. 예시` → `2. ` (9 다음은 10)
- `- 가` → `- `
- `- [ ] 할 일` → `- [ ] `
- 내용 없이 표시만 있는 줄(`2. `)에서 `Enter`를 누르면 표시를 지우고 목록을 끝냅니다.

`[[` 제목 후보 목록이 떠 있을 때는 이 기능이 쉬고 평소 줄 바꿈이 됩니다.

### Tab으로 들여쓰기

목록 줄에서 **Tab**은 그 줄을 두 칸 들여써 하위 목록으로 만듭니다. **Shift+Tab**은 한 단계 내어씁니다. 여러 줄을 골라 두고 누르면 고른 줄 전체가 옮겨집니다. 목록이 아닌 줄에서는 평소처럼 탭 글자가 들어갑니다.

```markdown
1. 준비
  1. 재료 사기
  2. 도구 챙기기
2. 실행
```

### 체크박스

`- [ ] 할 일`은 렌더링 칸에서 ☐로 보입니다. ☐를 누르면 ☑가 되고, 원문도 `[x]`로 바뀝니다. 다시 누르면 되돌아갑니다. 같은 노트에 체크 항목이 여럿이면 누른 항목만 바뀝니다.

체크 항목을 만들 때는 도구줄의 ☑ 단추 또는 `- [ ] 할 일`을 직접 씁니다.

### 표

`| 제목1 | 제목2 |` 형식의 마크다운 표를 씁니다. 편집 메뉴의 **표**로 틀을 넣을 수 있습니다. 웹에서 복사한 표는 마크다운 표로 바뀌어 붙습니다(7장).

### 코드와 인용

- 코드 블록은 ```` ``` ```` 사이에 씁니다. 언어 지정 코드는 ```` ```python ````처럼 씁니다.
- 인용은 `> 글`입니다.

## 6. 그림·영상·파일

### 넣기

도구줄의 🖼 단추(또는 편집 메뉴의 그림·영상·파일 항목)를 누르면 파일 고르기 창이 열립니다.

- 파일 종류 필터: **그림·영상**, 그림, 영상, 모든 파일
- 고른 파일은 노트 폴더의 `.resources`로 복사되고, 노트에는 `![이름](…)` 형식의 링크가 들어갑니다.
- 그림은 노트 안에 바로 보입니다.
- 영상(`.mp4`, `.webm`, `.m4v`, `.ogv`)과 음악(`.mp3`, `.flac`, `.m4a`, `.ogg`, `.wav`, `.opus`)은 노트 안에서 재생됩니다. 재생은 누르기 전에는 시작되지 않습니다.

### 영상 모양

영상은 다음 모양으로 써도 노트 안에서 재생됩니다. 웹 클리퍼로 스크랩한 노트에서도 같습니다.

```markdown
![클립](clip.mp4)
<video controls src="https://example.com/clip.mp4"></video>
[영상](clip.mp4)
```

재생 화면은 본문 칸 너비에 맞춘 16:9입니다. 노트를 열어도 자동으로 재생되지 않으며, 재생 단추를 눌러야 시작합니다. 노트에 든 소리·영상 파일 링크(`[곡](song.mp3)`)를 누르면 가져오기의 재생 화면과 같은 창이 열리고, 역시 재생 단추를 눌러야 시작합니다. 재생 화면을 쓸 수 없으면 `▶ 동영상 재생` 링크로 보이고, 누르면 재생 창이 열립니다. 편집 칸에서는 글자(링크)로 보입니다.

### 그림 다루기

- 렌더링 칸에서 그림을 **누르면 크게 보기**가 열립니다.
- 그림을 우클릭하면 **열기**, **복사**, **파일 위치 열기**, **삭제**를 고를 수 있습니다.
- 그림이 많은 노트는 그림을 네 장씩 화면 크기로 줄여 읽고, 한 번 읽은 그림은 기억해 둡니다.
- **GIF**는 첫 장면을 보여 주고, 재생 정보를 함께 엽니다.
- 본문에 글자로 박힌 긴 그림(base64)은 **도구 → 본문의 글자 그림을 파일로 일괄 분리…**로 파일로 옮깁니다(18장).

### 유튜브 영상

노트 안의 유튜브 링크는 썸네일로 보입니다. 누르면 재생 창이 열립니다. 재생 창의 종류는 **옵션 → 테마·색상**의 유튜브 영상 항목에서 고릅니다: 작은 재생 창(Brave 앱 창, 없으면 Edge, 주소창 없음) 또는 기본 브라우저.

## 7. 붙여넣기와 복사

- **붙여넣기** (`Ctrl+V`): 웹에서 복사한 **표**는 마크다운 표로 바뀌어 들어갑니다.
- **글자만 붙여넣기** (`Ctrl+Shift+V`): 서식 없이 글자만 넣습니다.
- **복사**: 렌더링 칸에서 고른 부분은 HTML로도 클립보드에 들어갑니다. 웹 편집기나 워드에 붙이면 표와 서식이 살아 있습니다.
- 자동 링크 `<https://…>`는 본문에서 링크로 보입니다.

## 8. 글 정리

메뉴줄의 **글 정리**는 편집 칸의 글을 한 번에 다듬습니다. 줄을 골라 두면 그 줄들만, 고른 글이 없으면 노트 전체를 고칩니다. 코드 블록 안은 건드리지 않고, `Ctrl+Z` 한 번으로 되돌립니다.

| 항목 | 하는 일 |
|---|---|
| 줄 앞 공백 지우기 | 줄 맨 앞의 공백·탭·전각 공백을 지웁니다. 들여 쓴 하위 목록은 그대로 둡니다. |
| 줄 끝 공백 지우기 | 줄 끝의 공백을 지웁니다(공백 두 칸으로 만든 줄 바꿈도 사라집니다). |
| 단어 사이 빈칸 줄이기 | 글자 사이에 두 칸 넘게 띈 곳을 한 칸으로 줄입니다. 인라인 코드 안은 건드리지 않습니다. |
| 여러 빈 줄을 하나로 | 빈 줄이 2줄 이상 이어진 곳을 1줄로 줄입니다. |
| 빈 줄 전부 없애기 | 빈 줄을 모두 없앱니다. |
| 같은 내용 삭제 | 같은 줄이 또 나오면 뒤의 것을 지웁니다. |
| 문단 줄 잇기 | 빈 줄로 나뉜 문단마다 한 줄로 잇습니다(PDF에서 복사해 끊긴 글). 제목·표·목록은 그대로 둡니다. |
| 문장마다 빈 줄 넣기 | 붙어 있는 줄 사이에 빈 줄을 넣어 줄마다 따로 한 문단이 되게 합니다. 한 줄 안의 문장은 나누지 않습니다. |
| 고른 줄 합치기 | 고른 줄을 한 줄로 합칩니다. |
| 줄 가나다순 정렬 | 고른 줄을 오름차순(또는 내림차순)으로 정렬합니다. |
| 대문자로 · 소문자로 | 고른 글자의 영문 대소문자를 바꿉니다. |

**문장마다 빈 줄 넣기** 예: 줄이 따로 떨어진 글이 `오늘은 날씨가 좋다.`, `공원에 갔다.`처럼 줄마다 붙어 있으면 그 사이에 빈 줄이 들어갑니다. 한 줄에 여러 문장이 이어져 있으면 줄 바꿈이 없어서 나뉘지 않습니다. 그런 글은 먼저 줄을 나눠 주세요.

항목마다 하는 일과 바꾸기 전·후 예시는 **글 정리 → 설명 보기…**에 있습니다.

## 9. 찾아 바꾸기

`Ctrl+H` 또는 **편집 → 찾아 바꾸기**를 누르면 찾기 막대 아래에 **바꿀 글** 줄이 붙습니다.

- **바꾸기**(또는 바꿀 글 칸에서 `Enter`): 지금 가리키는 곳을 바꾸고 다음 곳으로 갑니다.
- **모두 바꾸기**: 노트 전체를 바꿉니다. 편집 칸에서 여러 줄을 골라 두었으면 그 안에서만 바꿉니다.

대소문자는 구분하지 않습니다. 정규식은 쓰지 않습니다.

## 10. 위키 링크

위키 링크는 노트끼리 이어 주는 기능입니다. **옵션 → 일반 → 위키 링크**에서 켜고 끕니다. 끄면 `[[ ]]`는 그냥 글자가 됩니다.

### 쓰는 법

| 쓰는 법 | 뜻 |
|---|---|
| `[[노트 제목]]` | 그 제목의 노트로 가는 링크 |
| `[[노트 제목#절]]` | 그 노트의 특정 절(제목)로 가는 링크 |
| `[[노트 제목\|표시글]]` | 링크 글자를 다른 말로 보임 |
| `![[노트 제목]]` | 그 노트 내용을 본문에 포함해 보임 |
| `![[노트 제목#절]]` | 그 노트의 특정 절만 포함 |

- `[[`를 치면 제목 후보 목록이 뜹니다. 위·아래로 고르고 `Enter` 또는 `Tab`으로 넣습니다.
- 제목은 대소문자와 앞뒤·연속 공백을 무시하고 맞춥니다.
- 같은 제목의 노트가 여럿이면 **가장 최근에 고친 노트**로 연결됩니다.
- 없는 제목의 링크는 붉게 보입니다. 누르면 그 제목으로 새 노트를 만들 수 있습니다.
- 코드 블록 안의 `[[ ]]`는 링크가 되지 않습니다.
- 포함(`![[ ]]`)은 포함 속의 포함까지 6단계까지 펼치고, 한 번에 15만 자까지 펼칩니다. 순환(자기 자신을 포함)은 막습니다.

### 괄호 없이 연결 (톰보이 방식)

**옵션 → 일반 → "괄호 없이 제목과 같은 낱말도 연결"**을 켜면, 평범한 글 속에서 다른 노트의 제목과 같은 낱말이 자동으로 링크가 됩니다. 기본은 꺼짐입니다.

### 같은 노트북 안으로 제한

**옵션 → 일반 → "위키 링크를 같은 노트북 안으로 제한"**을 켜면 최상위 노트북 하나가 위키 하나가 됩니다. 링크, 포함, 자동완성, 연결된 노트, 제목 중복 검사가 그 노트북 안에서만 일어납니다. 같은 제목이라도 노트북이 다르면 만들 수 있습니다.

### 같은 제목 막기

위키 링크를 켜 두면 같은 제목의 노트는 만들 수 없습니다. 제목을 바꾸려 하면 막습니다.

### 연결된 노트 보기

노트 목록에서 노트를 우클릭해 **연결된 노트 보기…**를 고르면 두 목록이 나옵니다.

- **이 노트를 가리키는 노트**: 이 노트로 링크를 건 노트들
- **이 노트가 가리키는 노트**: 이 노트가 링크한 노트들

항목을 두 번 누르면 그 노트가 열립니다.

## 11. 태그

### 태그 쓰는 법

- 본문의 `#태그`
- 머리말의 `tags:` 줄
- 문서 맨 아래의 `태그: a, b` 줄

이 셋을 모두 태그로 읽습니다.

### 태그 입력

노트 아래의 태그 입력칸에 태그를 치고 `Enter`를 누르면 태그가 칩(태그 + ×)으로 쌓입니다. 입력칸은 다음 태그를 받습니다. 칩의 ×를 누르면 뺍니다.

### 태그 목록

사이드바의 태그 목록에서:

- 정렬: **빈도순** 또는 **이름순**(한글·영문 구분)
- 태그를 우클릭해 **태그 이름 변경…**, **태그 삭제…**를 합니다.
- 노트 목록에서 여러 노트를 고르고 **태그 추가…**로 한꺼번에 붙일 수 있습니다.
- **태그 추가·고치기…**(노트 목록 우클릭)로 노트 하나의 태그를 고칩니다.

태그 목록의 범위는 **전체**와 **현재 노트북**을 고를 수 있습니다.

### 자동 태그

**도구 → 자동 태그 추가…**는 문서마다 가장 많이 나온 낱말 세 개를 태그 후보로 뽑습니다. 확인 창에서 고른 것만 추가됩니다. 기존 태그는 지우지 않으며, 다시 실행해도 같은 태그가 늘지 않습니다.

## 12. 검색

### 찾기

| 방법 | 하는 일 |
|---|---|
| `Ctrl+F` (편집 → 문서에서 찾기) | 지금 노트 안에서 찾습니다. |
| `Ctrl+Shift+F` (편집 → 모든 파일에서 검색) | 노트 전체에서 찾고, 가져온 파일도 찾습니다. |

검색어를 치면 목록이 바로 좁혀집니다. 한글을 치는 중에도 결과가 따라옵니다.

### 검색 문법

- 공백 = AND: `회의록 예산`
- `OR`, `NOT`: `회의록 AND (예산 OR 일정) NOT 취소`(대문자만 연산자로 인식)
- 기호도 가능: `&`(AND), `|`(OR), `!`(NOT)
- `"정확한 구절"`
- 태그: `#프로젝트`, 또는 `태그: a, b` 줄
- 기간: `date:20240101`(그 날), `date:202401`(그 달), `date:2024`(그 해), `date:20101011-20240104`(그 사이), `date:20240101-`(그날부터), `date:-20240104`(그날까지). `날짜:`, `기간:`으로 써도 됩니다.

### 고급 검색

검색창의 **고급 검색**을 열면 조건을 골라 AND·OR·NOT으로 묶을 수 있습니다. 기간, 태그, 확장자, 프로그램 같은 조건을 쓸 수 있습니다. 조건이 걸리면 목록 위에 "고급 검색"이 표시됩니다.

### 검색 범위와 옵션

- **문서 내부 검색**(검색창 옆 체크): 끄면 제목과 태그에서만 찾고, 켜면 본문과 가져온 문서 안의 글까지 찾습니다. 가져온 폴더가 있을 때만 보입니다.
- **자동완성**: 켜면 입력 중에 최근 검색, 파일 제목, 태그 후보가 뜨고 목록을 밀어 내립니다. 기본은 꺼짐입니다.
- 검색어가 제목에 있는 노트는 정렬과 관계없이 위에 나옵니다.

### 정렬

검색창 아래의 단추로 정렬합니다.

- **관련도순**: 검색어와 가까운 순서(기본)
- **수정순**: 마지막으로 고친 시각 순
- **생성순**: 만든 시각 순(웹 클리퍼로 가져온 노트는 머리말의 `created`)
- **제목순**: 제목 순서

같은 단추를 한 번 더 누르면 오름·내림차순이 바뀝니다.

### 저장된 검색

검색식과 기간, 태그, 정렬을 **저장**(검색창 옆 단추)하면 사이드바의 **저장된 검색**에 이름을 붙여 보관합니다(스마트 폴더). 저장된 검색을 누르면 같은 조건으로 바로 열립니다.

- 우클릭으로 이름을 바꾸거나 지웁니다.
- **지금의 검색으로 덮어쓰기**로 조건을 바꿉니다.
- 검색어, 기간, 태그가 모두 비어 있으면 저장할 수 없습니다.

### 랜덤 노트

검색창 옆 **랜덤** 단추는 노트 하나를 무작위로 골라 엽니다. 목록을 모든 파일로 넓혀 그 노트를 선택해 보여 줍니다.

## 13. 노트북

노트북은 폴더입니다. 하위 폴더는 하위 노트북입니다.

- **파일 → 새 노트북**(`Ctrl+Shift+N`) / **새 하위 노트북**
- 노트북 우클릭: **하위 노트북 만들기**, 이름 바꾸기, 삭제
- 노트 우클릭 → **노트북으로 이동**으로 노트를 다른 노트북으로 옮깁니다.
- **노트북 삭제(휴지통)**: 노트북 안의 노트를 모두 휴지통으로 보냅니다(19장).
- 노트북 목록의 메뉴에 **저장 폴더 전체 삭제(휴지통)**가 있습니다. 노트 폴더 전체를 휴지통으로 보내는 것이라 영향이 큽니다. 누르기 전에 한 번 더 확인하세요.

## 14. 즐겨찾기

- 노트를 고른 뒤 `Ctrl+D`, 또는 노트 우클릭 → **즐겨찾기 추가**로 넣습니다. 다시 누르면 뺍니다.
- 편집 칸 위의 별로도 같은 일을 합니다.
- 사이드바의 **즐겨찾기**에서 모아 봅니다.
- 즐겨찾기 목록은 노트 파일을 바꾸지 않고 설정 폴더의 작은 파일에 적습니다. 폰과도 함께 맞춥니다.
- 즐겨찾기 기능은 **옵션 → 일반 → 기능**에서 끌 수 있습니다.

## 15. 달력·할일·공수달력

사이드바의 **달력·할일**을 고르면 노트 자리에 달력과 할일 화면이 열립니다. 이 기능은 옵션 → 일반의 기능 항목에서 끌 수 있습니다.

### 달력

- 날짜를 누르면 그 날의 할일이 아래에 나옵니다.
- 공휴일이 표시됩니다. 옵션의 **구글 달력에서 대한민국 공휴일 가져오기**를 켜면 로그인 없이 공개 달력에서 한 달에 한 번 받아 씁니다. 받지 못하면 내장 표(2024~2030년)를 씁니다.
- **오늘** 단추로 오늘 달로 갑니다.
- 날짜 입력은 `2026-09-14`나 `20260914`로 직접 쓸 수 있습니다.

### 할일

- **할일 추가…**: 날짜를 고르고 할 일을 씁니다. 추가한 날과 완료한 날을 적을 수 있습니다.
- 할일 앞의 ☐를 누르면 오늘 날짜로 완료됩니다.
- 할일을 우클릭하면 **변경**과 **삭제**를 합니다.
- **오늘 완료된 항목 숨기기**로 정리합니다.

### 공수달력(건설·일용직용)

옵션 → 기능의 **공수달력**을 켜면 쓸 수 있습니다.

- 날짜마다 **공수**를 적습니다. **공수 직접 입력…**으로 소수 값도 넣을 수 있고, **공수 지우기**로 없앱니다.
- 화면 아래에 이 달의 공수 합계, 일당(합계 × 단가), 일비(출근한 날 수 × 일비)가 나옵니다.
- **일비(하루)**도 날짜마다 적을 수 있습니다.

## 16. 아웃라이너 폴더

노트 폴더 안에 **아웃라이너** 폴더를 만들면 그 안의 노트는 WorkFlowy처럼 점(●) 계층으로 씁니다.

- `Enter`: 새 항목. 커서 뒤의 글은 새 항목으로 옮겨집니다.
- `Tab` / `Shift+Tab`: 들여쓰기 / 내어쓰기
- 줄 맨 앞에서 `Backspace`: 앞 항목에 붙입니다. 빈 항목이면 지웁니다.
- 항목을 접고 펼칩니다.

저장되는 파일은 일반 마크다운 목록(`.md`)이라 다른 편집기나 폰에서도 그대로 열립니다. 기능은 **옵션 → 일반 → 기능**에서 끌 수 있습니다.

## 17. 노트 목록과 이동

### 노트 목록 우클릭

노트를 우클릭하면 다음 메뉴가 나옵니다.

- **즐겨찾기 추가 / 해제**(`Ctrl+D`)
- **태그 추가·고치기…**
- **노트 속성…**, **노트 버전…**
- **연결된 노트 보기…**
- **노트북으로 이동**
- **경로 복사**, **파일 위치 열기**
- **휴지통으로 보내기**

가져온 파일(PDF, 음악, 동영상)을 우클릭하면 **연결 프로그램으로 열기**, **파일 위치 열기**가 나옵니다. 메모는 **메모…**로 적습니다.

### 이동

- **이동 → 뒤로** (`Ctrl+-`), **앞으로** (`Ctrl++`): 본 순서대로 노트를 오갑니다. 목록에서도 그 노트가 선택됩니다. 랜덤으로 본 노트도 기록에 남습니다.
- **보기 → 새로 고침** (`F5`) 또는 목록 위 ⟳: 앱 밖(탐색기 등)에서 노트를 지우거나 옮겼을 때 다시 읽습니다. 노트·노트북·태그·즐겨찾기·달력·가져온 문서를 모두 다시 읽습니다.
- **보기 → 노트 목록 보기** (`Ctrl+Shift+L`): 목록을 켜고 끕니다.

## 18. 도구 메뉴

| 항목 | 하는 일 |
|---|---|
| 복원 지점… | 여러 노트를 한 시점으로 되돌립니다. 필요할 때 직접 만들 수 있습니다(19장). |
| 전체 변경 이력… | 노트의 수정·이동·삭제 기록을 시간순으로 봅니다. |
| 자동 태그 추가… | 본문에서 태그 후보를 뽑아 확인 후 추가합니다(11장). |
| 중복 노트 찾기… | 내용이 같거나 거의 같은 노트를 찾아 묶어 보여 줍니다. 정리할 노트는 휴지통으로 보내집니다. |
| 스크랩 군더더기 정리… | 웹 스크랩에서 여러 노트에 똑같이 나오는 메뉴·"맨위로" 같은 줄을 찾아 지웁니다. 같은 사이트 노트에서 기준 비율과 최소 노트 수를 정하고, 지우지 않을 줄을 고를 수 있습니다. |
| 안 쓰는 미디어 파일 정리… | 어느 노트도 쓰지 않는 그림·첨부를 찾아 **휴지통으로 보냅니다**. 파일 열기·위치 열기도 됩니다. |
| 본문의 글자 그림을 파일로 일괄 분리… | 본문에 글자로 박힌 긴 그림(base64)을 리소스 파일로 옮기고 노트를 고칩니다. 바뀌기 전 내용은 노트 버전에 남습니다. |
| 중복 이미지 찾기… | 내용이 같은 그림 파일을 묶어 보여 줍니다. 묶음을 펼치면 그 그림을 쓰는 노트가 보이고, 노트 이름을 누르면 그 노트로 갑니다. **그림만 있는 노트 정리…**는 글이 거의 없고 같은 그림만 가진 노트를 묶어, 고른 묶음을 휴지통으로 보냅니다. 남기는 노트는 가장 먼저 만든 1개입니다. |
| 빈 스크랩 다시 받기… | 출처 주소는 있는데 본문이 빈 옛 스크랩을 찾습니다. **다음 10개 열기**로 브라우저에서 열어 조플린 클리퍼로 다시 스크랩한 뒤 **다시 채워진 빈 노트 정리…**를 누르면 옛 빈 노트를 휴지통으로 보냅니다. 연 줄은 `[열었음]`, 채워진 줄은 `[채워짐]`으로 표시합니다. |

## 19. 안전망: 휴지통·노트 버전·복원 지점·변경 이력

### 휴지통

- 삭제한 노트는 `.trash`에 보관되고 **30일** 뒤 완전히 지워집니다. 휴지통 화면에서 남은 날수를 볼 수 있습니다.
- 휴지통에서 **복원**하거나 **완전히 삭제**할 수 있습니다. **휴지통 비우기**는 모두 지웁니다.
- 자동 삭제를 끌 수도 있습니다("자동 삭제 안 함").

### 노트 버전

- 노트를 고칠 때마다 이전 내용을 노트별로 보관합니다. 기본은 **노트당 10개**, 새 버전 간격 **1분**입니다.
- 버전을 만드는 때: 노트를 연 뒤 처음 고칠 때(그 직전 내용), 그 뒤로는 간격이 지난 뒤 고칠 때.
- **편집 → 노트 버전…**에서 보고 골라 되돌립니다.
- 옵션 → 노트 버전에서 기록을 켜고 끄고, 보관 개수와 간격을 정합니다. 간격을 0으로 두면 자동 저장할 때마다 만듭니다.

### 복원 지점

- 여러 노트를 한 시점의 상태로 되돌리는 기능입니다. 윈도의 복원 지점과 같은 생각입니다.
- **도구 → 복원 지점…**에서 직접 만들고, 목록에서 골라 되돌립니다. 비교도 할 수 있습니다.
- 리소스 폴더를 옮기기 전처럼 큰 작업 전에는 앱이 자동으로 복원 지점을 만듭니다.

### 전체 변경 이력

**도구 → 전체 변경 이력…**은 노트의 수정, 이동, 삭제를 시간순으로 기록합니다. 언제 무엇을 바꿨는지 확인할 수 있습니다.

## 20. 웹 클리퍼

브라우저의 **조플린 클리퍼**(크롬 확장)로 웹 페이지를 이 앱에 바로 스크랩합니다.

1. **옵션 → 웹 클리퍼**에서 **웹 클리퍼 서비스 사용**을 켭니다.
2. 크롬 웹스토어에서 조플린 클리퍼 확장을 설치합니다. 옵션 화면에 웹스토어와 GitHub 링크가 있습니다.
3. 클리퍼 옵션에 **포트**와 **토큰**을 넣습니다. 두 값은 이 옵션 화면에 있습니다.

- 서버는 이 컴퓨터의 `127.0.0.1`에서만 열립니다(다른 컴퓨터에서 접속할 수 없습니다). 포트는 41184부터 41194 중 빈 것을 씁니다.
- 토큰 칸의 **복사**로 복사하고, **토큰 새로 만들기**로 바꿀 수 있습니다. 새 토큰을 만들면 확장의 토큰도 바꿔야 합니다.
- 스크랩하면 본문 맨 위에 `원본: 주소` 줄이 붙습니다. 렌더링 칸에서는 숨기고 문서 정보에 주소로 보입니다.
- 본문 첫 줄이 노트 제목과 같으면 중복을 피하려고 뺍니다.
- 클리퍼로 새 노트가 들어오면 알림이 뜹니다.

## 21. 외부 폴더 가져오기

노트 폴더 밖에 있는 PDF, 텍스트, 음악, 동영상 같은 파일을 노트처럼 검색하고 보려면 외부 폴더를 가져옵니다. 원본 파일은 건드리지 않고 읽기만 합니다.

### 추가하기

1. **파일 → 폴더 가져오기…** 또는 **옵션 → 가져오기**를 엽니다.
2. **폴더 추가…**로 노트 폴더 밖의 폴더를 고릅니다. 노트 폴더와 겹치는 폴더는 가져올 수 없습니다.
3. 읽을 파일 종류(확장자)를 고릅니다. 기본은 `pdf`, `txt`, `md`, `mp3`, `mp4`이며, 그 밖의 확장자는 직접 적을 수 있습니다.
4. **지금 다시 읽기**를 누릅니다.

처음 읽을 때 파일이 많으면 시간이 걸리고, 이후에는 바뀐 파일만 다시 읽습니다. 앱을 켜고 잠시 뒤 바뀐 파일은 저절로 다시 읽습니다.

- **문서 안의 글도 색인**: 켜면 PDF, TXT, DOCX의 본문과 MP3의 태그·가사까지 찾습니다. 끄면 파일 이름과 경로로만 찾습니다(빠르고 색인이 작아집니다).
- 글을 읽는 도구가 없는 확장자는 이름만 색인됩니다. 설정 화면에 빠진 도구가 있으면 알려 줍니다.
- **목록에서 빼기**는 색인만 지우고 원본과 태그·메모는 그대로 둡니다.

### 보기

가져온 파일을 목록에서 누르면 노트 칸 안에서 열립니다.

- **PDF**: 쪽 넘기기와 찾기가 되는 보기로 엽니다.
- **음악·동영상**(mp3, flac, m4a, ogg, wav, opus / mp4, webm): 재생 목록 화면으로 엽니다. 곡이 끝나면 다음 곡으로 넘어갑니다.
- 처음에는 연 파일이 든 폴더의 곡만 목록에 넣습니다. 재생 막대 아래의 폴더 고르기에서 다른 폴더 하나를 고르거나, **○○ + 하위 폴더**를 골라 그 아래의 곡을 모두 넣을 수 있습니다(예: 뮤직 + 하위 폴더 → 장르별 폴더 전부).
- **랜덤**을 켜면 목록을 섞어 겹치지 않게 한 바퀴 돌고, **반복** 단추는 누를 때마다 반복 안 함 → 전체 반복 → 한 곡 반복으로 바뀝니다. 다음에 열 때도 그대로입니다.
- 열기만 해서는 재생하지 않습니다. 다른 노트로 가거나 창을 트레이로 보내면 재생이 멈춥니다.
- 머리줄의 **뽑은 글로 보기**를 누르면 색인해 둔 글로 바뀝니다.
- 이 보기는 PC의 WebView2 런타임이 필요합니다(Windows 11에는 기본으로 있습니다). 없으면 윈도 미리보기나 뽑은 글로 보입니다.
- PDF 하나만 든 노트는 윈도 기본 PDF 뷰어로 바로 보여 줍니다.

### 연결 프로그램

가져온 파일을 우클릭해 **연결 프로그램으로 열기**를 쓰거나, 확장자마다 연결 프로그램을 따로 정할 수 있습니다.

- PDF·TXT·JPG·WEBP: WaterView, NeeView 같은 문서·이미지 뷰어
- MP3·MP4: Windows Media Player, VLC 같은 미디어 플레이어

MP3·MP4를 열 때는 같은 폴더의 미디어 파일도 함께 넘깁니다. 재생목록을 지원하는 플레이어에서는 폴더 안의 곡을 이어서 재생할 수 있습니다. 반복·셔플은 플레이어 설정을 따릅니다.

## 22. 노트 폴더와 그림 저장 위치

**옵션 → 폴더**에서 정합니다.

- **노트 폴더**: 노트북은 폴더, 노트는 `.md` 파일입니다. **변경…**으로 옮길 수 있고, **노트 폴더 열기**로 탐색기에서 봅니다.
- **그림·첨부(리소스 폴더)**: 기본은 노트 폴더 안의 숨김 폴더 `.resources`입니다. 노트에는 노트 위치 기준의 상대 경로로 연결됩니다.
- 예전 방식의 다른 폴더(예: `_resources`, `attachments`, `images`)를 쓰고 있다면 **볼트 안으로 옮기기**나 **다른 폴더를 .resources로 바꾸기…**를 누릅니다. 그림 파일을 옮기고, 모든 노트의 그림 링크도 함께 고칩니다. 옮기기 전에 복원 지점을 먼저 만듭니다.

## 23. 글꼴과 테마

### 글꼴

**옵션 → 글꼴**에서 정합니다.

- **화면 글꼴**: 목록, 렌더링, 표, 메뉴에 씁니다.
- **고정폭 글꼴**: 마크다운 편집과 코드에 씁니다.
- **노트 목록**과 **노트**(편집·렌더링)의 글자 크기와 굵기를 따로 정합니다. 미리보기를 보고 **적용**을 누르면 바로 바뀝니다. **기본값으로**는 되돌립니다.

### 테마

**옵션 → 테마·색상**에서 정합니다.

- 자주 쓰는 다섯 가지 테마 중에서 고르면 바로 적용됩니다.
- **내 테마 만들기**: 배경색과 강조색(선택한 글, 버튼, 링크, 태그)을 색 고르기 창에서 정합니다. 배경이 어두우면 글자는 밝게, 밝으면 어둡게 자동으로 맞춥니다.

## 24. 옵션(설정 메뉴) 전체

**설정 → 옵션…**(`Ctrl+,`)에서 다음 탭을 고칩니다.

| 탭 | 내용 |
|---|---|
| 일반 | 위키 링크(켜기, 괄호 없이 연결, 노트북 안으로 제한), 기능(즐겨찾기·아웃라이너 폴더·달력·할일·공수달력), 편집기 보기(마크다운만·분할·렌더링만), 창의 닫기 버튼(트레이 또는 바로 종료), 화면 구성(노트북·태그·노트 목록·문법 해설 보기) |
| 달력·할일 | 구글 공휴일 받기, 공수달력 설정 |
| 색인 | 노트와 가져온 폴더의 색인 상태. **md 노트 다시 훑기**, **가져온 폴더 다시 읽기** |
| 폴더 | 노트 폴더 위치, 그림(리소스) 폴더 위치와 이전 |
| 가져오기 | 외부 폴더 추가·빼기, 읽을 확장자, 문서 안의 글 색인 |
| 글꼴 | 화면·고정폭 글꼴, 목록·노트 글자 크기와 굵기 |
| 테마·색상 | 기본 테마 다섯 가지와 내 테마, 유튜브 영상을 여는 재생 창 |
| 노트 버전 | 버전 기록 켜기, 노트당 보관 개수, 새 버전 간격 |
| 동기화 | Syncthing 설치·실행, 폰 연결, 기기, 무엇을 어느 방향으로 맞출지 |
| 웹 클리퍼 | 서비스 켜기, 포트, 토큰, 확장 설치 링크 |

## 25. 동기화(컴퓨터와 폰)

컴퓨터와 폰은 서버를 거치지 않고 **Syncthing**으로 직접 맞춥니다. 노트는 어디에도 올라가지 않습니다.

### 처음 연결하기

1. **옵션 → 동기화**에서 **Syncthing 설치**를 누릅니다. 공식 릴리스를 내려받아 SHA-256으로 확인한 뒤 앱 안에 숨겨 실행합니다.
2. **동기화 사용**을 켭니다. 켜면 앱을 켤 때 함께 시작하고, 끌 때 함께 멈춥니다.
3. 폰 앱의 **설정 → 동기화 → 연결 마법사**에서 **폰 연결하기…**를 누르면 컴퓨터에 QR 코드가 나옵니다. 폰에서 QR을 찍으면 연결 요청이 옵니다.
4. 컴퓨터의 **허용**을 누르면 연결됩니다.
5. 폰에서 받을 노트 폴더를 확인합니다.

QR을 만들 수 없으면 기기 ID를 직접 넣을 수 있습니다. **기기 추가…**로 상대 기기의 ID를 넣고, **기기 빼기**로 지웁니다. 이 컴퓨터의 기기 ID는 옵션 화면에 있습니다.

### 무엇을 맞출지

**무엇을 어느 방향으로 맞출까**에서 정합니다.

- **Markdown 노트 전체**: 노트 폴더의 노트(기본: 양방향)
- **미디어(그림·첨부)**: `.resources` 폴더(기본: 양방향)
- **가져온 문서 요약**: 가져온 파일의 폰용 요약(기본: 컴퓨터 → 폰)
- **변경 이력(.history)**, **휴지통(.trash)**: 파일이 아주 많아 기본은 끕니다. 문서를 다 맞춘 뒤에 켜세요.
- 복원 지점(`.snapshots`)은 컴퓨터 전용이라 보내지 않습니다.

방향은 **양방향**, **컴퓨터 → 폰**, **폰 → 컴퓨터**, **동기화 안 함** 중에서 고릅니다.

- **외부 폴더 지정…**: 노트 폴더 밖의 가져온 폴더도 폰과 맞출 수 있습니다. 노트 폴더와 겹치는 폴더는 고를 수 없습니다.
- **새 방식으로 바꾸기…**: 노트북별 설정을 노트 폴더 전체 설정으로 바꿉니다. 예전의 **노트북 따로 설정…**은 새 방식에서 없어집니다.
- 컴퓨터와 폰의 규칙이 다르면 동기화를 멈추고 알려 줍니다. 두 쪽을 같게 맞추면 다시 시작합니다.
- 폰에서 바꾼 것과 컴퓨터에서 바꾼 것이 부딪히면 **동기화 충돌 해결…**(노트 목록 우클릭 메뉴)에서 골라 고칩니다. 충돌 파일은 자동으로 덮어쓰지 않습니다.

### 최근부터 단계별로 받기

노트가 많을 때 최근 노트를 먼저 받을 수 있습니다.

- 앱은 노트를 머리말 날짜(`updated`, 없으면 `created`)로 시기별 단계로 나눕니다. 각 노트가 쓰는 그림은 같은 단계에 묶습니다.
- 폰은 1단계(가장 최근)부터 받고, 다 받으면 다음 단계를 엽니다.
- 컴퓨터는 아직 열지 않은 단계의 파일을 가려서 폰이 받지 못하게 합니다. 앱이 켜져 있는 동안 5초마다 다음 단계를 엽니다.
- 설정 화면에서 **열린 단계 n / 전체**로 진행을 봅니다.

### 상태 보기

동기화 화면에서 **상태 갱신**을 누르면 기기 연결, 받는 중인 파일, 남은 용량과 시간을 봅니다.

### 창을 닫아도

트레이로 보내면 앱이 계속 실행되어 동기화도 계속됩니다. 완전히 끄면 동기화도 멈춥니다.

처음 연결하기 전에 양쪽 노트 폴더를 백업해 두세요.

## 26. 업데이트

- **도움말 → 업데이트 확인…**: 최신 릴리스를 확인합니다. 새 버전이 있으면 변경 내용을 보여 주고 내려받을지 묻습니다.
- 내려받은 `iamtalkernote.exe`는 릴리스에 적힌 SHA-256과 맞는지 확인한 뒤에만 바꿉니다. GitHub 주소가 아니면 중단합니다.
- 바꾼 뒤 새 버전이 자동으로 다시 시작됩니다.
- 소스(`.pyw`)로 실행 중이면 자동으로 바꾸지 않고 알려 줍니다.

## 27. 언어

- 창 오른쪽 위의 **언어 단추**(깃발과 `KO` 또는 `EN`)를 누르면 언어 목록이 펼쳐집니다. 고르면 바로 바뀌고 설정에 저장됩니다.
- 처음 실행할 때는 윈도 표시 언어를 따릅니다(한국어 윈도는 한국어, 그 밖은 영어).
- 영어 번역이 없는 일부 문장은 한국어로 남을 수 있습니다.

## 28. 트레이와 창 닫기

- **옵션 → 일반 → 창의 닫기(X) 버튼**에서 정합니다. 기본은 **트레이**(작업표시줄 알림 영역)로 보내는 것입니다. **바로 종료**로 바꿀 수도 있습니다.
- 트레이 아이콘을 누르면 창이 다시 열립니다. 아이콘에 마우스를 올리면 버전이 보입니다. 우클릭 → **종료**로 끕니다.
- **파일 → 종료**(`Alt+F4`)와 트레이의 종료는 언제나 바로 끕니다.

## 29. 도움말 메뉴

- **사용 설명서 (GitHub)…**(`F1`): 이 문서를 엽니다.

- **iamtalkernote 정보 (버전)**: 버전, 노트 폴더 위치, 저장소 주소를 보여 줍니다.

## 31. Android 앱

서랍에는 모든 노트, 노트북, 태그, 가져온 파일, 휴지통, 설정이 있습니다. 노트를 길게 누르면 여러 노트를 고를 수 있습니다.

노트를 열고 **편집**을 누르면 자동 저장됩니다. 검색, 태그, 노트 버전, 공유, 이름 바꾸기, 옮기기, 휴지통 기능을 씁니다.

### 공유로 스크랩하기

휴대폰의 공유 메뉴에서 바로 스크랩할 수 있습니다.

1. 브라우저나 다른 앱에서 저장할 웹페이지·글·사진·파일을 엽니다.
2. **공유**를 누르고 **iamtalkernote**를 고릅니다.
3. 제목과 저장할 노트북을 확인하고 저장합니다.

스크랩은 일반 노트로 저장되므로 태그, 검색, 즐겨찾기, 휴지통을 그대로 씁니다. 동기화되어 있으면 컴퓨터에서도 곧바로 보입니다.

컴퓨터가 가져온 파일의 요약은 `.imported`를 통해 목록과 검색에 나옵니다. 요약은 읽기 전용입니다.

## 32. 파일 구조와 백업

```text
노트 폴더/
├─ *.md          노트
├─ .resources/   그림·영상·첨부
├─ .trash/       휴지통
├─ .history/     변경 이력·노트 버전
├─ .snapshots/   복원 지점
├─ .imported/    가져온 파일 요약
└─ .sync/        동기화 정보·단계 목록

%APPDATA%\iamtalkernote\config.json   앱 설정
```

노트 폴더 전체를 복사하면 가장 간단한 백업입니다. 앱 밖에서 `.md`를 고치면 다음 실행 때 외부 수정으로 기록될 수 있습니다.

## 33. 알려진 한계

- 노트 칸 안의 브라우저(PDF·음악·동영상 보기), 영상 재생 화면, 윈도 미리보기는 Windows 전용이며 WebView2가 필요합니다.
- 스캔 PDF의 글자 인식(OCR)과 음성 인식은 지원하지 않습니다.
- 가져온 원본 파일은 앱에서 고치거나 옮기거나 지우지 않습니다.
- 유튜브는 노트 안에서 재생하지 않고 외부 창으로 엽니다.
- 편집 칸에서는 영상이 글자(링크)로 보입니다. 재생 화면은 렌더링 칸에서 봅니다.
- Android에서 가져온 파일의 원본을 열려면 그 파일도 동기화되어 있어야 합니다.
- 찾아 바꾸기는 정규식을 지원하지 않습니다.
- `app/editor.py`는 **위키나루**라는 별도 프로그램의 파일입니다. iamtalkernote는 여기서 서식 정의와 그림 불러오기 기능만 가져다 씁니다. 위키나루 자체는 이 문서에서 다루지 않습니다.
