# 화면 엔진을 Tkinter 에서 HTML(웹 브라우저) 엔진으로 바꾸면

2026-11-02 검토. **결론: 전부 갈아엎지는 말고, 노트 보기 칸 하나에만 WebView2 를 끼워 넣는 쪽부터 시작한다.**

## 지금 구조

- 화면은 Tkinter 로 그리고, 마크다운 렌더링은 `Text` 위젯에 직접 그린다(`app/notes.py` 4,300줄 포함 앱 전체 1만 7천 줄).
- pdf·mp3·Office 문서는 이미 **윈도 미리보기 처리기**(Edge·Media Player 등)를 노트 칸 안에 끼워 넣어 보여 주고(`winpreview.py`), 그 밖은 기본 프로그램으로 연다.
- exe 는 PyInstaller 로 만든 35MB 한 파일.

## 바꾸면 좋아지는 것

| 항목 | 효과 |
| --- | --- |
| GIF·영상·오디오·pdf | 브라우저가 노트 안에서 바로 재생·표시 (영상은 광고 없는 임베드까지 가능) |
| 표·수식·긴 글·그림 많은 노트 | 레이아웃을 엔진이 맡아 빠르고 정확함. 지금 Tk 의 표·그림 계산 문제가 사라짐 |
| 한글 입력 | 입력기 조합을 브라우저가 처리 → `ime.py` 의 우회가 필요 없어짐(조합 중 글자 깜빡임류 버그 원천 해결) |
| 글꼴·테마 | CSS 로 해결 |

## 걸림돌과 해결책

| 걸림돌 | 해결책 |
| --- | --- |
| **전체를 다시 짜야 한다.** 화면 코드(Tk 위젯)가 앱 대부분이라 사실상 재작성 | 한 번에 바꾸지 않는다. **1단계: 렌더링 칸만 WebView2 로** (저장·검색·동기화·색인 등 Python 코드는 그대로) |
| Tk 창 안에 WebView2 를 넣기 어렵다 | 지금 쓰는 방식과 같은 길: 별도 작은 프로세스(pywebview)를 띄워 그 창을 `SetParent` 로 노트 칸에 붙인다. 이 컴퓨터에 `pywebview 6.2.1`·`pythonnet 3.1` 이 이미 있어 시험은 바로 가능 |
| WebView2 런타임이 없는 PC | 윈도 10/11 은 대부분 Edge 와 함께 깔려 있음. 없으면 지금처럼 Tk 렌더링으로 **되돌아가기(대체 경로 유지)** |
| exe 가 커지고 PyInstaller 설정이 복잡해짐 | pywebview 는 .NET 연동(pythonnet)이 필요해 수 MB 늘어남. 용량이 아주 커지는 Electron·CEF 는 쓰지 않는다(CEF 파이썬 판은 최신 파이썬을 지원하지 않음) |
| 파이썬 3.14 호환 | pywebview 6.2.1·pythonnet 3.1 이 이 PC 에서 설치돼 있으니 **1단계 시험으로 먼저 확인** |
| 노트 1만 4천 개 목록·검색 | 목록은 지금 Tk 그대로 두면 문제없음(2단계 이후에야 웹으로 옮길지 결정) |
| 편집기(원문 칸) | 1단계에서는 Tk `Text` 유지. 나중에 CodeMirror 로 바꿀지 판단 |
| 보안 | 노트 안 HTML/스크립트는 실행하지 않는 렌더링 결과만 넣고, 로컬 파일은 읽기 전용 주소로만 연다 |

## 단계

1. **렌더링 칸만 WebView2** — 마크다운 → HTML 변환(위키나루 엔진의 출력을 재사용), GIF·영상·오디오 태그 사용. 실패하면 Tk 렌더링. (작은 시험 앱으로 파이썬 3.14·PyInstaller 에서 도는지부터)
2. 가져온 문서 칸에도 같은 WebView2 사용: pdf 는 브라우저 뷰어, mp3 는 오디오 플레이어. (지금 처리기 방식과 겹치므로 이득이 크지 않으면 생략)
3. 편집기·목록까지 웹으로 옮기는 전면 재작성은 **1단계 결과를 보고** 정한다.

## 엔진과 별개로 필요한 것: 확장자별 연결 프로그램

zip 만화 파일처럼 웹 엔진이 열 수 없는 형식은 어떤 엔진이어도 **외부 프로그램에 맡겨야** 한다. 엔진과 상관없이 따로 만들 수 있다.
- 옵션에 "확장자 → 프로그램" 표(예: `zip` → 만화 뷰어 exe)를 두고, 가져온 파일을 열 때(더블클릭·우클릭 → 연결 프로그램으로 열기) 이 표를 먼저 본다. 없으면 윈도 기본 프로그램.
- 보안: 실행 파일은 사용자가 직접 지정한 것만, 파일 경로는 인자로만 넘긴다(셸 해석 없이).
