# iamtalkernote 동기화 개발 방향

사용자가 정한 설계 방향입니다. 데스크톱(이 저장소)과 안드로이드([iamtalkernote-android](https://github.com/iamtalker/iamtalkernote-android)) 둘 다 이 문서를 따릅니다.

## 1. 기본 구조
- 별도의 중앙 서버 없이 P2P 방식으로 기기 간 동기화한다.
- Syncthing을 파일 전송 엔진으로 활용한다.
- iamtalkernote가 동기화 대상, 방향, 경로 등 전체 정책을 관리한다.

## 2. 동기화 모듈
데이터를 모듈별로 분리하고 각 모듈에 독립적인 동기화 설정을 제공한다.
- 미디어 파일 전체
- Markdown 파일 전체
- Markdown 특정 노트북별
- 외부 폴더별

## 3. 동기화 정책
각 모듈마다 다음 설정을 독립적으로 지정한다.
- 양방향 동기화
- PC → 모바일 단방향 동기화
- 모바일 → PC 단방향 동기화
- 동기화 제외

## 4. 저장 경로
- PC는 외부 폴더를 기존 위치에 유지한다.
- 모바일은 외부 폴더를 앱 전용 저장 공간에 저장한다.
- 기기마다 실제 저장 경로가 달라도 동일한 동기화 대상으로 연결한다.
- Sync Manager가 기기별 로컬 경로를 관리한다.

## 5. 설계 원칙
- 사용자는 데이터 모듈별로 동기화 여부와 방향을 간편하게 설정한다.
- 동기화 엔진과 앱의 동기화 정책을 분리한다.
- 향후 전송 엔진을 교체하더라도 동기화 정책과 사용자 설정은 유지할 수 있도록 설계한다.

## 구현 메모 (아직 코드 없음)
- 정책(모듈 목록·방향·기기별 경로)은 노트 폴더 안 파일 하나(예: `.sync/policy.json`)에 두어 어느 전송 엔진이든 읽을 수 있게 한다.
- 전송 엔진(Syncthing) 쪽은 어댑터로 분리한다. 정책 → Syncthing 폴더·`.stignore`·폴더 종류(send-only/receive-only/send-receive) 변환만 어댑터가 맡는다.
- 기기별 로컬 경로는 정책 파일이 아니라 기기 로컬 설정(Sync Manager)에 둔다.
